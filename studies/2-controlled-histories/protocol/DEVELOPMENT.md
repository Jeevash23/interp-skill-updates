## Question and scope

Does a history containing mostly independent changes to constituent functions cause more selective future learning than a history of joint changes, when exposure, target norms, target-transition size and recent experience are controlled? Distinguish compositional computation from selective plasticity. The conclusion concerns the specified finite tasks and small networks, not all neural networks or language models.

The classification pilot failed because the model did not generalize composition before adaptation. The continuation uses continuous lookup functions with additive composition y=f(a)+g(b). The domain remains eight values. Each primitive is queried separately; combined training excludes the same two cyclic diagonals, leaving 48 observed and 16 unseen pairs. Inputs are two eight-dimensional one-hot slots, with zero in a missing primitive slot. There is no environment ID, target value or explicit function table in an input.

## Matching the histories

For each task draw centered orthonormal f basis vectors u and v with RMS one. Draw the centered g basis in the null space of the training incidence matrix applied to the f basis, then orthonormalize and scale to RMS one. This deliberately makes the f and g training contributions orthogonal. Four versions of each function are u, v, -u and -v. Reserve a new centered RMS-one vector orthogonal to each function's training basis for adaptation. The g family is generated conditional on f to enforce matching; it is not claimed to be independently drawn from f.

Use eight environments: 00, 20, 22, 02, 11, 31, 33 and 13. Independent-change history traverses that list in that order. Joint-change history traverses 00, 11, 02, 13, 22, 33, 20 and 31. Repeat each cycle three times, followed by the common suffix 00,20,22,02,00. The two histories have identical environment counts, initial environment and final five environments. The independent cycle contains six one-function transitions and two joint transitions; every joint-cycle transition changes both functions. The common suffix is shared by both.

A single-function transition flips one RMS-one vector by 180 degrees. A joint transition changes each function by 90 degrees. Both produce exactly the same mean squared change of training targets: 3.5. Every training environment has target mean square 1.75. These equalities are checked before training for every task. They match aggregate transition size, not which examples or primitive targets change. Different per-function temporal structure is the intended treatment; generalization beyond this constructed family is not assumed.

## Adaptation and causal interventions

Clone each final checkpoint and change f only or g only to its reserved function. Expose only the changed primitive's eight new labels to the optimizer. Use fresh, momentum-free SGD at learning rate 0.05 for 200 steps. Record all 80 predictions and parameter displacement/path length at every step. Primary comparison is unrestricted learning at step 200. The changed and unchanged primitive normalized RMSEs and updated unseen-combination error are separate outcomes. A predeclared matched-progress diagnostic uses the first step with changed-primitive RMSE at most 0.10, retaining failures to reach it.

Compare unrestricted updates with: freezing the 32 readout weights; three fixed random masks freezing 32 of the 288 potentially active weights for that update direction; readout-only updates; no update; continued old-primitive training; and normalized-gradient updates of length 0.01 per step. Potentially active weights are the changed input slot's 256 hidden weights plus 32 readout weights. Random masks are paired across histories and selected independently of outcomes for each update direction. Normalized-gradient updates control parameter path length across histories; report any zero-gradient exception. The random-mask controls match potentially active parameter count, not functional rank or trainability. No-update and old-label conditions are scored against updated targets and retain all failures.

Before updates, cache hidden activations for both primitive sets. With disjoint input slots, updating f by plain SGD leaves the g input columns unchanged. For these architectures, the resulting g-output drift is exactly the fixed g hidden matrix multiplied by the change in shared readout weights. Test this identity numerically through the trajectory and intervene on the readout to test necessity/sufficiency against random masks. This identity is a structural prediction of the specified model, not a new general theorem or evidence of an emergent neuron module. Report combined-input transfer separately, since the ReLU model need not preserve additivity.
