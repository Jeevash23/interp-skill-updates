# Post-confirmation duration control

This additional control is declared after examining the completed 512-model confirmation and before running this control. The fixed-200-step primary history comparisons remain unchanged. They did not establish a practically useful independent-history advantage. Fixed-readout updates preserved the unchanged primitive exactly but left mean changed-primitive RMSE around 0.20–0.21 at step 200. Preservation alone therefore cannot be counted as complete selective adaptation.

Continue the same fixed-readout intervention, starting again from every confirmation base checkpoint, for a fixed **1,000** SGD steps at the same rate 0.05. There is no new base training, task sampling, initialization, architecture, optimizer or history comparison. Include all 512 base models and both change directions: **1,024 trajectories**. Do not select successes or extend beyond this budget after seeing results. Save all 80 predictions every twenty steps, the endpoint weights and the first states reaching changed-primitive RMSE <=0.10 and <=0.01. Retain failures to reach either threshold.

This is an explicitly post-confirmation feasibility/learning-speed control for the intervention, not an additional confirmatory test of the history hypothesis. Compare progress times with the original unrestricted first-0.10 times descriptively. Report endpoint changed/stable/combined errors and success counts, including differences in available optimization steps. Do not pool it into the six primary history intervals.

Use an independent NumPy implementation of the same fixed-readout SGD. For all 1,024 trajectories its step-200 predictions must reproduce the previously saved PyTorch fixed-readout results within 1e-8. Check fixed readout, unchanged input columns, stable predictions and independently reconstructed endpoint predictions. Additionally rerun 1,000 steps using PyTorch for the predeclared first/last-family, first-initialization sample, both architectures/histories/directions: sixteen complete trajectories. Compare endpoint weights/predictions to NumPy within 1e-8. Resource limits remain two GiB available memory and three GiB disk.

The control can show that this explicit restriction allows eventual selective adaptation. It cannot show that a training history discovered the restriction, that it is the only successful intervention, or that a fixed-step comparison was equally fast.
